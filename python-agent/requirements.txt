# ==================== 第 7 周（RabbitMQ 消费者 + 重试计数）====================
# pika：MQ 消费（app/mq_consumer.py）。用 pika 1.x 的 BlockingConnection +
#       basic_consume(auto_ack=False) + basic_qos(prefetch_count=1) 手动确认。
pika>=1.3,<2.0
# redis：同一 taskId 的**重试次数**计数（mq:retry:{taskId}，TTL 3600s）。
#        刻意不用 RabbitMQ 的 x-death / redelivered 当计数：requeue 重投时它们不递增，
#        会导致失败消息无限重投。
redis>=5.0

#    只有真正启动消费者（python -m app.mq_consumer）时才报错并提示安装命令。
